# Changelog

## 0.1.0

- Initial release: squad window with one row per marine showing health, stress, resolve
  (Evolved rules), effective attributes and skill pools.
- GM drag-and-drop of characters or actor folders; remove individual marines or clear the list.
- Squad stored as a world setting; players see only marines they can observe.
- Live updates on actor, item and effect changes.
- Talent count under each marine's name; hover to list their talents.
- Horizontal (one row per marine, the default) and vertical (one column per marine) layouts;
  toggle from the window corner or in module settings. Remembered per browser.
- Text size buttons in the window corner, in four steps from 90% to 130%.
